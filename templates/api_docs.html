API Documentation

Version 1.0

Use the MCP Server

For AI agent use, the Beekeeper MCP server is the recommended interface. It exposes all operations as MCP tools — no shell commands, no binary to install.

MCP Setup Guide

Overview

The Beekeeper API provides programmatic access to all project management, training control, and monitoring features. All endpoints return JSON responses with a consistent envelope format.

Base URL: http://{{ request.host }}/api/v1

Authentication

API requests require authentication via API key. Include the key in the X-API-Key header: 

curl -H "X-API-Key: your-api-key-here" http://{{ request.host }}/api/v1/projects

Generate API keys from the Admin Panel.

Response Format

All API responses use a consistent JSON envelope:

Success Response

{
  "success": true,
  "data": { ... }
}

Error Response

{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable error message"
  }
}

Projects

GET /projects

List all projects with basic info and training status.

curl http://{{ request.host }}/api/v1/projects

POST /projects

Create a new project from a git repository.

curl -X POST http://{{ request.host }}/api/v1/projects \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-project",
    "git_url": "https://github.com/user/repo.git",
    "branch": "main",
    "python_version": "3.12",
    "train_file": "train.py",
    "env_type": "venv"
  }'

Required fields:

  • name - Project name (alphanumeric, hyphens, underscores only)
  • git_url - Git repository URL

Optional fields:

  • branch - Git branch (default: "main")
  • python_version - Python version (default: "3.12")
  • train_file - Training script path (default: "train.py")
  • tensorboard_log_dir - TensorBoard logs directory (default: "runs")
  • output_paths - Workspace-relative output directories to protect (default: [])
  • requirements_file - Requirements file path (default: "requirements.txt")
  • env_type - Environment type: "venv" or "conda" (default: "venv")
  • setup_script - Optional setup script to run after dependency installation

GET /projects/{name}

Get detailed project info including training status.

curl http://{{ request.host }}/api/v1/projects/my-project

POST /projects/{name}/clone

Clone an existing project with a new name.

curl -X POST http://{{ request.host }}/api/v1/projects/my-project/clone \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-project-clone",
    "branch": "experimental"
  }'

Required fields:

  • name - New project name

Optional fields:

  • branch - Override the git branch (defaults to source project's branch)

Training Control

POST /projects/{name}/training/start

Start training for a project.

curl -X POST http://{{ request.host }}/api/v1/projects/my-project/training/start

Returns the process PID and TensorBoard port on success.

POST /projects/{name}/training/stop

Stop running training.

curl -X POST http://{{ request.host }}/api/v1/projects/my-project/training/stop

GET /projects/{name}/training/status

Get training status (running, idle, etc.).

curl http://{{ request.host }}/api/v1/projects/my-project/training/status

Logs & Monitoring

GET /projects/{name}/logs

Get log content. Use ?tail=N for last N lines.

curl "http://{{ request.host }}/api/v1/projects/my-project/logs?tail=100"

GET /projects/{name}/logs/stream

Server-sent events (SSE) stream of log updates.

curl -N http://{{ request.host }}/api/v1/projects/my-project/logs/stream

GET /projects/{name}/logs/analysis

Parse episode data from logs and return trend analysis (improving/stable/declining).

curl "http://{{ request.host }}/api/v1/projects/my-project/logs/analysis?tail=500"

Works for active runs without needing TensorBoard data.

TensorBoard Metrics

GET /projects/{name}/tensorboard/latest

Get metric analysis for the current or most recent run.

curl http://{{ request.host }}/api/v1/projects/my-project/tensorboard/latest

# With detail level
curl "http://{{ request.host }}/api/v1/projects/my-project/tensorboard/latest?detail=medium"

# Filter specific metrics
curl "http://{{ request.host }}/api/v1/projects/my-project/tensorboard/latest?metrics=loss,accuracy"

Query parameters:

  • detail - low (default), medium, or high
  • metrics - Comma-separated list of metric names to include

Branch Management

GET /projects/{name}/branches

List available branches from the remote repository.

curl http://{{ request.host }}/api/v1/projects/my-project/branches

POST /projects/{name}/branch

Switch to a different branch.

curl -X POST http://{{ request.host }}/api/v1/projects/my-project/branch \
  -H "Content-Type: application/json" \
  -d '{"branch": "experimental"}'

Checks for uncommitted changes before switching.

Files

GET /projects/{name}/files

List files in workspace root.

curl http://{{ request.host }}/api/v1/projects/my-project/files

GET /projects/{name}/files/{path}

Download a file or list directory contents.

# List directory
curl http://{{ request.host }}/api/v1/projects/my-project/files/subdir

# Download file
curl -O http://{{ request.host }}/api/v1/projects/my-project/files/model.pth

# Download directory as zip
curl -o workspace.zip "http://{{ request.host }}/api/v1/projects/my-project/files?zip=1"

Run History

GET /projects/{name}/runs

List training run history (last 20 runs).

curl http://{{ request.host }}/api/v1/projects/my-project/runs

GET /projects/{name}/runs/{run_id}

Get details for a specific run.

curl http://{{ request.host }}/api/v1/projects/my-project/runs/5

GET /projects/{name}/runs/{run_id}/metrics

Get TensorBoard metrics for a specific run.

curl http://{{ request.host }}/api/v1/projects/my-project/runs/5/metrics

Accepts same query parameters as /tensorboard/latest.

GET /projects/{name}/runs/{run_id}/log

Download archived log file for a run.

curl -O http://{{ request.host }}/api/v1/projects/my-project/runs/5/log

DELETE /projects/{name}/runs/clear

Clear all run history for a project.

curl -X DELETE http://{{ request.host }}/api/v1/projects/my-project/runs/clear

POST /projects/{name}/runs/cleanup-orphaned

Mark orphaned runs as canceled (stuck in "running" state after server restart).

curl -X POST http://{{ request.host }}/api/v1/projects/my-project/runs/cleanup-orphaned

System

GET /stats

Get system stats (CPU, RAM, GPU usage and availability).

curl http://{{ request.host }}/api/v1/stats

Agent Integration

GET /projects/{name}/agent/instructions

Download agent instructions as a markdown file for AI agents.

curl -o BEEKEEPER.md http://{{ request.host }}/api/v1/projects/my-project/agent/instructions

This file can be added to a project's CLAUDE.md or pasted into an AI agent's context to give it full access to Beekeeper functionality.

Example Workflows

Create and Start Training

# 1. Create project
curl -X POST http://{{ request.host }}/api/v1/projects \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-rl-project",
    "git_url": "https://github.com/user/rl-project.git",
    "branch": "main"
  }'

# 2. Wait for setup to complete (poll until setup_status is "ready")
curl http://{{ request.host }}/api/v1/projects/my-rl-project

# 3. Start training
curl -X POST http://{{ request.host }}/api/v1/projects/my-rl-project/training/start

# 4. Monitor logs
curl "http://{{ request.host }}/api/v1/projects/my-rl-project/logs?tail=50"

# 5. Check progress
curl http://{{ request.host }}/api/v1/projects/my-rl-project/logs/analysis

Clone Project for Experiments

# Clone existing project with different branch
curl -X POST http://{{ request.host }}/api/v1/projects/my-rl-project/clone \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-rl-project-experimental",
    "branch": "feature/new-reward"
  }'

# The cloned project will use the same settings but start fresh

Switch Branch and Retrain

# 1. Stop training if running
curl -X POST http://{{ request.host }}/api/v1/projects/my-project/training/stop

# 2. Switch branch
curl -X POST http://{{ request.host }}/api/v1/projects/my-project/branch \
  -H "Content-Type: application/json" \
  -d '{"branch": "experimental"}'

# 3. Start training on new branch
curl -X POST http://{{ request.host }}/api/v1/projects/my-project/training/start
