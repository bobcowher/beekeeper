Chain your projects into one repeatable run

A pipeline runs a list of steps in order: training runs on your projects, and shell tasks for the work between them, like fetching data, converting checkpoints or copying model files. Start it once and Beekeeper carries it through.

  1. fetch-data task
    ./download.sh
  2. pretrain train
    chess-base
  3. fine-tune train
    chess-ft
  4. export task
    cp model.pt /models/

Train steps

Queue a training run on one of your projects and wait for it to finish. They go through the project's normal queue, so parallel-run limits and GPU checks still apply.

Task steps

Run a shell command. Each pipeline run gets its own folder, $BEEKEEPER_PIPELINE_RUN_DIR, that tasks start in.

Handing off outputs

Every step can find the output folders of the steps before it: $BEEKEEPER_PREV_STEP_DIR or $BEEKEEPER_STEP_<NAME>_DIR.

When a step fails

The pipeline stops there. Fix the problem and Resume; it picks up at the failed step and reuses earlier steps' outputs.

What the definition looks like 
name: chess-factory
steps:
  - name: fetch-data
    type: task
    command: ./download.sh
  - name: pretrain
    type: train
    project: chess-base
  - name: fine-tune
    type: train
    project: chess-ft
    env_vars:
      EPOCHS: "3"
    # train.py reads $BEEKEEPER_STEP_PRETRAIN_DIR from its environment
  - name: export
    type: task
    command: cp "$BEEKEEPER_PREV_STEP_DIR/model.pt" /models/
