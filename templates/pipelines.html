Chain your projects into one repeatable run

A pipeline runs a list of steps in order: training runs on your projects, and shell tasks for the work between them, like fetching data, converting checkpoints or copying model files. Start it once and Beekeeper carries it through.

  1. fetch-data task
    chess · ./download.sh
  2. pretrain train
    chess · pretrain.py
  3. fine-tune train
    chess · finetune.py
  4. export task
    cp checkpoints/model.pt /models/

Train steps

Queue a training run on one of your projects and wait for it to finish. They go through the project's normal queue, so parallel-run limits and GPU checks still apply. Pick the script each step runs.

Task steps

Run a shell command. With a project, it runs in that project's workspace; without one, in the pipeline run's own folder.

Handing off outputs

inherit: [checkpoints] copies output paths from the step above into the step's run folder, so the script opens checkpoints/model.pt like it would on your laptop.

When a step fails

The pipeline stops there. Fix the problem and Resume; it picks up at the failed step and reuses earlier steps' outputs.

What the definition looks like 
name: chess-factory
steps:
  - name: fetch-data
    type: task
    project: chess              # runs in chess's workspace
    command: ./download.sh      # writes data/, an output path of chess
  - name: pretrain
    type: train
    project: chess
    script: pretrain.py
    inherit: [data]
  - name: fine-tune
    type: train
    project: chess
    script: finetune.py         # opens checkpoints/pretrained.pt
    inherit: [checkpoints, data]
    env_vars:
      EPOCHS: "3"
  - name: export
    type: task
    inherit: [checkpoints]
    command: cp checkpoints/model.pt /models/
