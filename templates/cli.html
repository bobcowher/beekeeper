Beekeeper CLI

Native binary for humans and AI agents

Overview

The Beekeeper CLI is a native Linux binary that wraps the REST API into a clean command-line interface. It is the recommended way for AI agents and human operators to interact with Beekeeper from a terminal.

The run analyze command provides a Synthesized View — a single high-signal verdict aggregating TensorBoard trends and log-based episode metrics — designed for AI agent consumption without requiring screenshots or manual parsing.

Installation

The CLI is a single statically-linked binary with no runtime dependencies.

⇓ Download beekeeper (Linux x86-64)

Or install directly from the terminal:

curl -o beekeeper http://{{ request.host }}/static/bin/beekeeper && chmod +x beekeeper

Configure via environment variables:

export BEEKEEPER_HOST="http://{{ request.host }}"
export BEEKEEPER_API_KEY="your-api-key-here"

Generate an API key from the Admin Panel. BEEKEEPER_HOST defaults to http://localhost:5000 if unset.

Command Reference

projects

Command Description
beekeeper projects list List all projects with name and training status
beekeeper projects info <name> Show detailed metadata: git URL, branch, setup status

training

Command Description
beekeeper training start <name> Start training; returns the process PID
beekeeper training stop <name> Stop the active training process
beekeeper training status <name> Show current training state

logs

Command Description
beekeeper logs get <name> [tail] Fetch last N lines of training output (default: 50)

run

Command Description
beekeeper run analyze <name> Synthesized View: aggregates TensorBoard trends + log episode metrics into a single high-signal report. Ideal for AI agents.

Examples

# Set up credentials
export BEEKEEPER_HOST="http://{{ request.host }}"
export BEEKEEPER_API_KEY="your-api-key-here"

# List all projects
./beekeeper projects list

# Check training state
./beekeeper training status my-project

# Tail 100 log lines
./beekeeper logs get my-project 100

# Get synthesized training analysis (best for AI agents)
./beekeeper run analyze my-project

# Start training
./beekeeper training start my-project

# Stop training
./beekeeper training stop my-project

Building from Source

Requires g++ with C++17 support and make.

git clone https://github.com/bobcowher/beekeeper-cli
cd beekeeper-cli
make
./beekeeper projects list
