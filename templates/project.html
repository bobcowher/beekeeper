                Agent ▶
            

            

                

                    Connect your agent via the Beekeeper MCP server. The MCP server exposes all operations as tools — no binary to install.
                


                
Step 1 — Add project instructions to your ML project repo:

                

                    
                        ⇓ Download BEEKEEPER_{{ project.name }}.md
                    
                    Copy into your project repo as CLAUDE.md
                

                
curl -o CLAUDE.md http://{{ host }}/api/v1/projects/{{ project.name }}/agent/instructions


                
Step 2 — Set up the MCP server:

                

                    
                        ⇓ Download mcp_server.py
                    
                    Save to your machine, then add to MCP config:
                

                
{
  "mcpServers": {
    "beekeeper": {
      "command": "python",
      "args": ["{{ mcp_server_path }}"],
      "env": {
        "BEEKEEPER_HOST": "http://{{ host }}",
        "BEEKEEPER_API_KEY": "your-api-key"
      }
    }
  }
}

                

                    Omit BEEKEEPER_API_KEY if auth is disabled.  ·
