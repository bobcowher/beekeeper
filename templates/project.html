Agent ▶

Connect your agent via the Beekeeper MCP server. Run these steps on your local machine — not the lab server.

Step 1 — Install the MCP server:

pip install beekeeper-mcp

Step 2 — Register the MCP server:

Claude Code — run once in your terminal:

claude mcp add beekeeper -s user -e BEEKEEPER_HOST=http://{{ host }} -- beekeeper-mcp

If auth is enabled, add -e BEEKEEPER_API_KEY=your-api-key before --. If beekeeper-mcp isn't found, run which beekeeper-mcp and use the full path.

Claude Desktop — add to ~/.claude/claude_desktop_config.json:

{
  "mcpServers": {
    "beekeeper": {
      "command": "beekeeper-mcp",
      "env": {
        "BEEKEEPER_HOST": "http://{{ host }}",
        "BEEKEEPER_API_KEY": "your-api-key"
      }
    }
  }
}

Add to ~/.codex/config.toml:

[mcp_servers.beekeeper]
command = "beekeeper-mcp"

[mcp_servers.beekeeper.env]
BEEKEEPER_HOST = "http://{{ host }}"
BEEKEEPER_API_KEY = "your-api-key"

Omit BEEKEEPER_API_KEY if auth is disabled. Use the full path for command if beekeeper-mcp isn't on your PATH.

Add to ~/.gemini/settings.json:

{
  "mcpServers": {
    "beekeeper": {
      "command": "beekeeper-mcp",
      "env": {
        "BEEKEEPER_HOST": "http://{{ host }}",
        "BEEKEEPER_API_KEY": "your-api-key"
      }
    }
  }
}

Restart Gemini CLI after saving. Omit BEEKEEPER_API_KEY if auth is disabled.

Add to ~/.qwen/settings.json:

{
  "mcpServers": {
    "beekeeper": {
      "command": "beekeeper-mcp",
      "env": {
        "BEEKEEPER_HOST": "http://{{ host }}",
        "BEEKEEPER_API_KEY": "your-api-key"
      }
    }
  }
}

Omit BEEKEEPER_API_KEY if auth is disabled.
